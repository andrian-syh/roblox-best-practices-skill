# Agents the installer can target, in addition to the always-included ./.agents/skills path.
# Read by bin/cli.js, install.ps1, and install.sh. Edit this file only.
#
# Format: Display Name|home-relative global skills path
# Lines starting with '#' and blank lines are ignored.
#
# Each path is the agent's documented global (home-directory) skills path, which often differs
# from its project path: Windsurf reads ~/.codeium/windsurf/skills, not .windsurf/skills.
# An agent counts as detected when the path minus its final "skills" segment exists in $HOME,
# so ".config/goose/skills" is detected by "~/.config/goose", never by "~/.config".
